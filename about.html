About SlotBooker

A high-performance, responsive slot and appointment scheduling web application built by Deepika.V using Python Flask and MySQL.

Built & Developed By
Deepika.V

Tech Stack

  • Developed By Deepika.V
  • Backend Framework Python (Flask 3.x)
  • Database Engine MySQL 8.0+ / PyMySQL Connector
  • ORM & Data Layer Flask-SQLAlchemy
  • Authentication Flask-Login & Werkzeug Security
  • User Interface Bootstrap 5, Bootstrap Icons, Vanilla JS

Key Capabilities

Double Booking Protection

Database level transactional locks and unique constraints prevent double reservations.

Batch Slot Generator

Automate schedules by generating slots across time intervals, dates, and hours.
